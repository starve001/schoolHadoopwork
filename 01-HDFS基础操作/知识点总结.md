# HDFS Java API 基础操作

## 一、实验目标
通过 Java API 操作 HDFS 文件系统，掌握 HDFS 的目录管理、文件上传下载、读写追加、元数据查看等核心操作。

## 二、核心知识点

### 1. Configuration 配置对象
```java
Configuration conf = new Configuration();
conf.set("dfs.client.block.write.replace-datanode-on-failure.policy", "NEVER");
```
- 自动加载 classpath 下的 `core-site.xml`、`hdfs-site.xml` 等配置
- `set()` 方法可在代码中动态覆盖配置项
- 关闭写失败时 DataNode 替换策略，避免单节点伪分布式环境下报错

### 2. 获取 FileSystem 实例
```java
URI uri = new URI("hdfs://localhost:9000");
FileSystem fs = FileSystem.get(uri, conf, "hadoop");
```
- `FileSystem.get(uri, conf, user)` 指定 HDFS 地址、配置、操作用户
- 操作完成后必须 `fs.close()` 释放资源（try-finally）

### 3. 常用操作方法对照表

| 操作 | API | 说明 |
|------|-----|------|
| 创建目录 | `fs.mkdirs(new Path("/path"))` | 递归创建 |
| 判断存在 | `fs.exists(path)` | 返回 boolean |
| 上传文件 | `fs.copyFromLocalFile(localPath, hdfsPath)` | 本地上传到HDFS |
| 下载文件 | `fs.copyToLocalFile(hdfsPath, localPath)` | HDFS下载到本地 |
| 判断目录/文件 | `fs.getFileStatus(path).isDirectory()` | 通过 FileStatus 判断 |
| 删除 | `fs.delete(path, true)` | true=递归删除 |
| 追加内容 | `fs.append(path)` 返回 FSDataOutputStream | 向已有文件末尾追加 |
| 文件复制 | `FileUtil.copy(fs, src, fs, dst, false, conf)` | HDFS内部复制 |
| 查看内容 | `fs.open(path)` 返回 FSDataInputStream | 配合 IOUtils.copyBytes |
| 列目录 | `fs.listStatus(path)` 返回 FileStatus[] | 获取元数据列表 |

### 4. 流式读写
```java
// 读文件到控制台
FSDataInputStream in = fs.open(hdfsPath);
IOUtils.copyBytes(in, System.out, 1024, true);

// 追加写入
FSDataOutputStream out = fs.append(hdfsPath);
out.write(content.getBytes(StandardCharsets.UTF_8));
out.close();
```
- `IOUtils.copyBytes(in, out, bufferSize, close)` 一次性完成流拷贝并关闭
- HDFS 文件默认不支持随机修改，只能 `append` 追加

### 5. FileStatus 元数据
```java
FileStatus[] status = fs.listStatus(hdfsPath);
for (FileStatus f : status) {
    f.getPath();            // 完整路径
    f.getLen();             // 文件大小（字节）
    f.getReplication();     // 副本数
    f.getOwner();           // 所有者
    f.getModificationTime(); // 修改时间
}
```

## 三、注意事项
1. 输出路径在 MapReduce 作业中**必须不存在**，否则报错；但 HDFS API 的 mkdirs 是幂等的
2. 操作用户需对 HDFS 对应目录有权限（这里用 hadoop 用户）
3. 伪分布式环境记得先启动 HDFS：`start-dfs.sh`
4. log4j 配置通过 `PropertyConfigurator.configure("src/log4j.properties")` 加载

## 四、运行方式
```bash
# 编译打包后
hadoop jar hadoop.jar edu.sugon.hdfs.HDFSOpt
```

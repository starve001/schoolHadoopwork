# 自定义 WritableComparable 二次排序

## 一、实验目标
实现图书馆借阅记录按「索书号 indexNo 升序，相同索书号再按卡号 cardNo 升序」的二次排序，掌握 Hadoop 自定义序列化对象和排序规则。

## 二、核心知识点

### 1. 为什么需要自定义 Writable
Hadoop 自带的 Text、IntWritable 只能表示单个值。当业务 Key 是多个字段的组合（如索书号+卡号）时，需要自定义一个类作为 Map 输出的 Key。

### 2. WritableComparable 接口四要素
自定义类必须实现 `WritableComparable<T>`，包含三个方法：

```java
class Book implements WritableComparable<Book> {
    // ① 序列化：把对象字段写入输出流
    @Override
    public void write(DataOutput out) throws IOException {
        out.writeUTF(cardNo);
        out.writeUTF(indexNo);
        // ... 所有字段按顺序写
    }

    // ② 反序列化：从输入流读取字段（顺序必须与 write 一致）
    @Override
    public void readFields(DataInput in) throws IOException {
        this.cardNo = in.readUTF();
        this.indexNo = in.readUTF();
        // ... 按相同顺序读
    }

    // ③ 排序规则：Shuffle 阶段按此方法结果排序
    @Override
    public int compareTo(Book o) {
        int cmp = this.indexNo.compareTo(o.indexNo);  // 第一排序字段
        if (cmp != 0) return cmp;
        return this.cardNo.compareTo(o.cardNo);       // 第二排序字段
    }
}
```

### 3. 序列化顺序原则
- `write()` 和 `readFields()` 的字段顺序**必须完全一致**
- 推荐用 `writeUTF/readUTF` 写字符串（自动带长度前缀）
- 必须有无参构造函数（Hadoop 反射创建对象时调用）

### 4. 二次排序原理
- Map 输出 Key 是 `Book` 对象
- Shuffle 阶段自动调用 `compareTo()` 排序
- `compareTo` 先比 indexNo，indexNo 相同再比 cardNo → 实现二级排序
- Value 用 `NullWritable.get()` 占位，因为只需要排序 Key

### 5. Mapper 解析
```java
static class BookMapper extends Mapper<LongWritable, Text, Book, NullWritable> {
    @Override
    protected void map(LongWritable key, Text value, Context context) {
        String[] fields = value.toString().split("\t");  // 制表符分隔
        if (fields.length < 11) return;
        Book book = new Book(fields[0], fields[1], ...);
        context.write(book, NullWritable.get());
    }
}
```
- 输入是制表符分隔的图书馆借阅记录
- 每行解析为一个 Book 对象直接作为 Key 输出
- Value 是 NullWritable，表示不需要 Value

### 6. Job 配置要点
```java
job.setMapOutputKeyClass(Book.class);       // Map输出Key是自定义Book
job.setMapOutputValueClass(NullWritable.class);
job.setOutputKeyClass(Book.class);          // 最终输出Key也是Book
job.setOutputValueClass(NullWritable.class);
```
- 没有 Reducer，Map 输出经过 Shuffle 排序后直接写文件
- 本质上是一个「全排序」作业

### 7. toString 方法
```java
@Override
public String toString() {
    return cardNo + "\t" + indexNo + "\t" + bookName + ...;
}
```
- Hadoop 输出时会调用 Key 的 toString() 写入文件
- 用制表符分隔方便后续 Hive/Excel 读取

## 三、扩展：二次排序进阶
如果需要「按第一字段分区，第二字段排序」，还需要：
1. 自定义 `Partitioner`：按 indexNo 分区
2. 自定义 `GroupingComparator`：按 indexNo 分组
3. 自定义 `SortComparator`：按 indexNo+cardNo 排序

本实验只需要全局排序，用默认 HashPartitioner 即可。

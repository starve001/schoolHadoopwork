# TopN 排序（Map 预聚合 + Reduce cleanup 全局排序）

## 一、实验目标
统计词频后取出现次数最多的前 N 个词（Top3）；图书馆热门书籍借阅次数 Top10。掌握 MapReduce 中实现全局排序取 TopN 的经典模式。

## 二、核心知识点

### 1. Mapper 生命周期方法
```java
@Override
protected void setup(Context context) {
    // Map任务启动时调用一次，初始化资源
    localMap = new HashMap<>();
}

@Override
protected void map(LongWritable key, Text value, Context context) {
    // 每行调用一次，本地累加，不直接 context.write
    localMap.merge(w, 1, Integer::sum);
}

@Override
protected void cleanup(Context context) {
    // Map任务结束时调用一次，输出本地聚合结果
    for (Map.Entry<String, Integer> e : localMap.entrySet()) {
        context.write(new Text(e.getKey()), new IntWritable(e.getValue()));
    }
}
```
- **setup()**：Map Task 初始化时执行一次，用于创建集合、读取配置
- **map()**：每行数据调用一次
- **cleanup()**：Map Task 处理完所有行后执行一次，用于收尾输出
- 本地 HashMap 预聚合 = 在 Map 端做 Combiner 的效果，大幅减少 Shuffle 数据量

### 2. Reducer cleanup 全局聚合排序
```java
@Override
protected void reduce(Text key, Iterable<IntWritable> values, Context context) {
    int sum = 0;
    for (IntWritable v : values) sum += v.get();
    wordMap.put(key.toString(), sum);  // 全部存入内存Map
}

@Override
protected void cleanup(Context context) {
    // 所有 reduce 调用完成后，统一排序取 TopN
    List<Map.Entry<String, Integer>> list = new ArrayList<>(wordMap.entrySet());
    Collections.sort(list, (o1, o2) -> o2.getValue() - o1.getValue()); // 降序
    int topN = Math.min(3, list.size());
    for (int i = 0; i < topN; i++) {
        context.write(new Text(list.get(i).getKey()),
                      new IntWritable(list.get(i).getValue()));
    }
}
```
- 因为只有一个 Reducer（默认 `setNumReduceTasks(1)`），cleanup 中能拿到全量数据
- 在 cleanup 中内存排序后截取前 N 个输出
- **关键前提**：TopN 必须只有一个 Reducer，否则每个 Reducer 只能拿到部分数据

### 3. 两种 TopN 实现方案对比

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| cleanup 内存排序（本实验） | 单Reducer全量入内存排序 | 简单直观 | 数据量大时内存溢出 |
| 多个Job链式（见08 StarCountcopliot） | 第一次统计，第二次按值排序 | 可扩展大数据量 | 多一轮IO |

### 4. BooksTop10 应用
- 输入：books.txt 每行是一个书名
- Mapper：本地 HashMap 统计每个书名出现次数
- Reducer：全局汇总后按借阅次数降序，取前 10

### 5. 性能优化要点
- Mapper 端 `localMap.merge()` 代替逐行 `context.write()`，减少 80%+ 的 Shuffle 数据
- 复用 Text/IntWritable 对象，避免频繁创建
- 排序用 `Collections.sort` + 匿名 Comparator

## 三、注意事项
1. TopN 作业必须保证 `setNumReduceTasks(1)`（默认就是1），否则结果不完整
2. 如果全量数据超过 Reducer 内存，应改用「二次排序 Job」方案
3. `Math.min(N, list.size())` 防止数据不足 N 条时数组越界

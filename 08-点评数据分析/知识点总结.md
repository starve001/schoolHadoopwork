# 点评数据分析（避暑山庄评论 CSV）

## 一、实验目标
基于 `避暑山庄评论.csv`（MongoDB 导出的游客评论数据）完成多项统计：省份列表、月度人数、星级分布、星级排序、省份综合指标。这是一组综合性 MR 作业练习。

## 二、数据字段
CSV 字段（索引从0开始）：
| 索引 | 字段 | 示例 |
|------|------|------|
| 0 | _id | MongoDB主键 |
| 1 | 昵称 | "游客123" |
| 2 | 评分星级 | "5分 非常棒" |
| 3 | IP属地 | "IP属地：河北" |
| 4 | 评论内容 | "山庄很美..." |
| 5 | 评论时间 | "2024-05-20 12:30:00" |

## 三、包含的子作业

### 1. ShengFenList —— 统计有哪些省份（去重列表）
```java
// Mapper：提取IP属地中的省份名
String address = fields[3].replaceAll("\"", "");  // "IP属地：河北"
String shengfen = address.split("：")[1];          // "河北"
context.write(shengfen, ONE);

// Reducer：不计数，只输出省份名本身
protected void reduce(Text key, Iterable<IntWritable> values, Context context) {
    context.write(key, result);  // result 是空 Text
}
```
- 本质是「Distinct 去重」：Shuffle 自动按 Key 分组，每个省份只到 Reduce 一次
- Reducer 不需要求和，只输出 Key 即可实现去重

### 2. MonthCount —— 统计各年月评论人数
```java
// Mapper：从时间字段提取"年月"
String ny = fields[5].replaceAll("\"", "");       // "2024-05-20 12:30:00"
String[] nySplit = ny.split("-");                  // ["2024","05","20 ..."]
String sf = nySplit[0] + nySplit[1];               // "202405"
context.write(nianyue, new LongWritable(1));
```
- 按「年月」聚合统计评论数量
- LongWritable 防止数量超过 int 范围

### 3. StarCount —— 各星级评分人数统计
```java
// Mapper：解析"5分 非常棒" → 提取"5分"
String star = cols[2].replace("\"", "").trim();
if (star.startsWith("1分") || star.startsWith("5分")) {
    word.set(star.split(" ")[0]);   // "5分"
    context.write(word, one);
}

// Reducer：用 TreeMap 按数量排序
TreeMap<Integer, ArrayList<Text>> countToStars = new TreeMap<>();
// reduce 中：sum 相同的星级归到一组
// cleanup 中：descendingKeySet() 按数量降序输出
```
- TreeMap Key 是统计数，Value 是同数量的星级列表
- `descendingKeySet()` 倒序遍历实现从多到少输出
- 修复点：去重避免同一星级重复添加

### 4. StarCountcopliot —— 双 Job 链式作业（统计+排序）
```
Job1（统计）: CSV → <星级, 数量>
     ↓ 输出到 HDFS
Job2（排序）: Job1输出 → <数量, 星级> → 自动排序 → <星级, 数量>
```
**Job1：统计各星级人数**
- Mapper：解析星级，输出 `<星级, 1>`
- Reducer：求和，输出 `<星级, 总数>`

**Job2：按人数排序**
```java
// SortMapper：交换 Key 和 Value
count.set(Integer.parseInt(cols[1]));  // 数量作为 Key
star.set(cols[0]);                      // 星级作为 Value
context.write(count, star);             // <IntWritable, Text>
// Shuffle 自动按 Key(数量) 升序排序

// SortReducer：换回原格式
context.write(val, key);  // <Text(星级), IntWritable(数量)>
```
- **核心思想**：把要排序的字段作为 Map 输出 Key，利用 Shuffle 自动排序
- 两个 Job 通过 HDFS 中间结果串联：Job1 的输出目录 = Job2 的输入目录
- `countjob.waitForCompletion(true)` 阻塞等待 Job1 完成后再启动 Job2

### 5. ProvinceZongHe —— 省份综合指标
```java
// Mapper：用自定义分隔符拼接多字段
String ss = "1@#@" + scoreStr + "@#@" + month;
context.write(shengfens, new Text(ss));  // <省份, "1@#@评分@#@月份">

// Reducer：
// - 人数 cnt
// - 平均分 mean = total / cnt
// - 最高分 maxnum
// - 最低分 minnum
// - 差评（最低分）出现最多的月份
```
- 用 `@#@` 作为自定义分隔符（避免与逗号、分号冲突）
- 一个 Mapper 输出 Value 携带多个字段，Reduce 端拆解计算多指标
- 输出：`月份  平均分  最高分  最低分  月份`

## 四、关键技术点汇总

| 技术点 | 用途 |
|--------|------|
| CSVReader | 正确解析带引号的 CSV 字段 |
| IP属地 split("：") | 从"IP属地：河北"提取省份 |
| TreeMap + descendingKeySet | 按值排序输出 |
| 双 Job 链式 | 第一次统计，第二次利用 Shuffle 排序 |
| 自定义分隔符 @#@ | Mapper 传递多字段组合值 |
| FileSplit 跳过表头 | `if(key.get()!=0)` 或 `startsWith("_id")` |

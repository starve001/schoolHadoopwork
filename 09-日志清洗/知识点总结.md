# 搜狗日志清洗（Map-only 作业）

## 一、实验目标
对搜狗搜索日志做数据清洗：过滤字段不足 6 列的脏数据，将空格分隔改为制表符分隔，输出干净数据供后续 Hive 分析。掌握「无 Reducer」的 Map-only 作业模式。

## 二、数据样例
搜狗日志每行（空格分隔）：
```
访问时间  用户ID  [查询词]  点击URL  排名  序号
20240101000000  123456  [Hadoop教程]  http://xxx  1  1
```

## 三、核心知识点

### 1. Map-only 作业（无 Reducer）
```java
job.setMapperClass(SogouMapper.class);
job.setMapOutputKeyClass(Text.class);
job.setMapOutputValueClass(NullWritable.class);

// 关键：设置 Reducer 任务数为 0
job.setNumReduceTasks(0);
```
- `setNumReduceTasks(0)` 表示不经过 Shuffle 和 Reduce 阶段
- Map 输出直接写入 HDFS
- 适用于：数据清洗、格式转换、过滤等不需要聚合的作业
- **优势**：没有 Shuffle，速度极快；Map 任务数 = 文件分片数

### 2. NullWritable 的使用
```java
// Mapper 输出
context.write(new Text(sb.toString()), NullWritable.get());
```
- NullWritable 是 Hadoop 的空类型，不占序列化空间
- 当只需要 Key 不需要 Value 时用 NullWritable
- 输出文件每行只写 Key（记录内容），Value 为空

### 3. 数据清洗逻辑
```java
String line = value.toString().trim();
if (line.isEmpty()) return;                    // 跳过空行

String[] fields = line.split("\\s+");         // 按一个或多个空格切分
if (fields.length < 6) return;                // 过滤字段不足6列的脏行

// 用制表符重新拼接（方便 Hive 导入）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < fields.length; i++) {
    sb.append(fields[i]);
    if (i < fields.length - 1) sb.append("\t");
}
context.write(new Text(sb.toString()), NullWritable.get());
```
- `\\s+` 正则匹配一个或多个空格/Tab
- 字段数不足 6 说明数据残缺，丢弃
- 输出改为 `\t` 分隔，因为 Hive 默认分隔符是制表符

### 4. Map-only vs 带 Reduce 的区别
| 对比项 | Map-only | 带 Reduce |
|--------|----------|-----------|
| Reducer 数量 | 0 | 默认1 |
| Shuffle | 无 | 有（排序+分组） |
| 输出文件数 | = Map任务数 | = Reduce任务数 |
| 适用场景 | 清洗、过滤、格式转换 | 聚合、统计、排序 |
| 输出有序性 | 无序 | 按Key有序 |

### 5. 输出路径自动清理
```java
Path out = new Path(outputPath);
FileSystem fs = out.getFileSystem(conf);
if (fs.exists(out)) fs.delete(out, true);
```

## 四、注意事项
1. Map-only 作业不需要设置 Reducer 类和输出 Value 类型
2. 多个 Map Task 会产生多个输出文件（part-m-00000, part-m-00001...）
3. 后续导入 Hive 时，输入路径指定目录即可，Hive 会读取目录下所有 part 文件

## 五、运行方式
```bash
# 上传原始日志
hadoop fs -put 搜狗日志查询分析.sample /001/input/

# 运行清洗
hadoop jar hadoop.jar hadoop01.SogouMain

# 查看清洗结果（多个Map输出文件）
hadoop fs -ls /001/output/
hadoop fs -cat /001/output/part-m-00000 | head

# 后续可导入 Hive
# CREATE TABLE sogou (...) ROW FORMAT DELIMITED FIELDS TERMINATED BY '\t';
# LOAD DATA INPATH '/001/output' INTO TABLE sogou;
```

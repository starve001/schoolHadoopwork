# 运营商基站停留时间分析

## 一、实验目标
基于基站日志，统计每个用户在各时段内于每个基站的停留时长。掌握通过 Configuration 传递运行参数、日期时间差计算、按 Key 分组排序后求相邻记录差值的分析模式。

## 二、数据样例
基站日志每行：`用户ID  ... 基站位置 ... 通讯时间(HH:mm:ss)`

## 三、核心知识点

### 1. 通过 Configuration 传递外部参数
```java
// main 中设置参数
Configuration configuration = new Configuration();
configuration.set("timeRange", args[0]);  // 如 "09-18-24"

// Mapper setup 中读取
@Override
protected void setup(Context context) {
    Configuration conf = context.getConfiguration();
    String timeRange = conf.get("timeRange");
    // 解析 "09-18-24" → [9, 18, 24]
}
```
- `configuration.set(key, value)` 在提交 Job 前设置
- Mapper/Reducer 通过 `context.getConfiguration().get(key)` 读取
- 参数会随作业分发到所有 Task 节点

### 2. 时段切分逻辑
```java
// timeRange = "09-18-24" 表示三个时段：0-9, 9-18, 18-24
for (int i = 0; i < timeRangeList.length; i++) {
    if (hour < timeRangeList[i]) {
        startHour = (i == 0) ? 0 : timeRangeList[i-1];
        endHour = timeRangeList[i];
        break;
    }
}
// 输出 <用户ID\t时段, 基站-时间>
context.write(new Text(userId + "\t" + startHour + "-" + endHour),
              new Text(baseStation + "-" + timeString));
```
- 根据小时数判断该记录属于哪个时段
- Key 是「用户+时段」，保证同一用户同时段的记录分到同一 Reduce

### 3. Reducer 中时间差计算
```java
// 按时间排序所有记录
Collections.sort(valueList, (o1, o2) ->
    o1.split("-")[1].compareTo(o2.split("-")[1]));

// 计算相邻记录时间差 = 在该基站的停留时长
for (int i = 0; i < valueList.size() - 1; i++) {
    String station = valueList.get(i).split("-")[0];
    DateFormat df = new SimpleDateFormat("HH:mm:ss");
    Date d1 = df.parse(valueList.get(i).split("-")[1]);
    Date d2 = df.parse(valueList.get(i+1).split("-")[1]);
    long minute = (d2.getTime() - d1.getTime()) / 1000 / 60;
    residenceTimeMap.merge(station, minute, Long::sum);
}
```
- 同一用户在某基站最后一次出现 → 下一次出现在另一基站
- 两条相邻记录的时间差 ≈ 在该基站的停留时长
- 用 `SimpleDateFormat` 解析时间，`getTime()` 转毫秒再求差

### 4. TreeMap 自动排序
```java
Map<String, Long> residenceTimeMap = new TreeMap<>();
```
- TreeMap 默认按 Key 字典序排序
- 最终输出按停留时间降序再排序一次

### 5. 命令行参数
```java
public static void main(String[] args) {
    if (args == null || args.length != 1) {
        throw new RuntimeException("argument is not right!");
    }
    configuration.set("timeRange", args[0]);
}
```
- 运行时传入时段配置：`hadoop jar xxx.jar PhoneMain 09-18-24`
- 传 `"1"` 表示不分时段，按全天统计

## 四、业务逻辑总结
```
日志记录：用户A 8:00 在基站X，8:30 在基站X，9:15 在基站Y
→ 用户A在基站X停留 8:30-8:00 = 30分钟
→ 用户A在基站Y停留 9:15-8:30 = 45分钟（直到下一条记录）
```

## 五、注意事项
1. 时间解析要处理 `date1.after(date2)` 的异常情况（数据乱序）
2. 数据量 ≤ 1 条时无法计算时间差，直接 return
3. 输出 Key 用 `\t` 分隔多字段，方便后续解析
4. 不分时段模式（timeRange=1）只输出停留最长的基站

## 六、运行方式
```bash
hadoop fs -put pos.txt /001/input/

# 分时段统计（0-9, 9-18, 18-24）
hadoop jar hadoop.jar hadoop01.PhoneMain 09-18-24

# 全天统计
hadoop jar hadoop.jar hadoop01.PhoneMain 1

hadoop fs -cat /001/out/part-r-00000
```

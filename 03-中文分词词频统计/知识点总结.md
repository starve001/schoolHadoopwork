# 中文分词词频统计（HanLP + CSV 解析）

## 一、实验目标
对 CSV 格式的中文评论文本做词频统计：使用 HanLP 进行中文分词，结合停用词过滤，输出有意义的中文词汇频次。

## 二、数据样例
输入：`避暑山庄评论.csv`，每行是一条评论记录（MongoDB 导出 CSV），字段以逗号分隔，评论内容在第 5 列（索引 4）。

## 三、核心知识点

### 1. HanLP 中文分词
```java
List<Term> termList = HanLP.segment(line);
for (Term term : termList) {
    // term.word 是词语，term.nature 是词性
}
```
- `HanLP.segment()` 将一句中文切分为词语序列
- 返回 `List<Term>`，每个 Term 包含 `word`（词语）和 `nature`（词性）

### 2. 停用词过滤
```java
if (CoreStopWordDictionary.shouldInclude(term)) {
    wordWritable.set(term.word);
    context.write(wordWritable, countWritable);
}
```
- `CoreStopWordDictionary.shouldInclude(term)` 判断该词是否为停用词
- 停用词：的、了、是、我、你、啊 等无实际意义的虚词
- 过滤后只保留有实际语义的词

### 3. CSV 解析（opencsv）
```java
Reader r = new StringReader(pings);
CSVReader reader = new CSVReader(r);
String[] lines = reader.readNext();
reader.close();
```
- 评论内容本身可能含逗号、引号，不能直接 `split(",")`
- 用 `CSVReader` 正确解析带引号的 CSV 字段
- `StringReader` 将字符串包装为字符流供 CSVReader 读取

### 4. 表头跳过
```java
if (ll.startsWith("_id") || ll.trim().isEmpty()) return;
```
- MongoDB 导出的 CSV 第一行是字段名（_id, 昵称, 评分...）
- 跳过表头行和空行

### 5. Map/Reduce 输出类型
- Map 输出：`<Text(词语), IntWritable(1)>`
- Reduce 输出：`<Text(词语), IntWritable(总频次)>`
- 与英文 WordCount 一致，区别只在 Mapper 内的分词逻辑

### 6. 输出目录自动清理
```java
FileSystem fs = outputPath.getFileSystem(conf);
if (fs.exists(outputPath)) {
    fs.delete(outputPath, true);
}
```
- MR 要求输出目录不存在，所以运行前先判断并删除
- 这是生产代码的标准写法，避免反复手动删目录

## 四、依赖 Jar 包
| 依赖 | 用途 |
|------|------|
| hanlp-port-1.x.x.jar | 中文分词 |
| opencsv-x.x.jar | CSV 解析 |
| hadoop-common / mapreduce-client | Hadoop API |

## 五、运行方式
```bash
# 上传 CSV
hadoop fs -put 避暑山庄评论.csv /041601/

# 运行
hadoop jar hadoop.jar hadoop01.WordCountCN

# 查看高频词（取前20）
hadoop fs -cat /041601/WordCountCN/part-r-00000 | sort -k2 -nr | head -20
```

## 六、与英文 WordCount 的区别
| 对比项 | 英文 WordCount | 中文词频 |
|--------|---------------|----------|
| 分词方式 | `split(" ")` 空格切分 | HanLP 语义分词 |
| 停用词 | 无 | CoreStopWordDictionary 过滤 |
| 输入格式 | 纯文本行 | CSV 多字段 |
| 字段提取 | 整行分词 | 取第5列评论内容 |

# WordCount 词频统计（MapReduce 入门模板）

## 一、实验目标
实现经典 WordCount：统计文本中每个单词出现的次数，掌握 MapReduce 编程三段式结构。

## 二、核心知识点

### 1. MapReduce 编程三段式
一个标准 MR 作业 = **Mapper + Reducer + Job驱动**

```
Input → [Map] → Shuffle(Sort/Partition) → [Reduce] → Output
```

### 2. Mapper 阶段
```java
static class WordCountMapper extends Mapper<LongWritable, Text, Text, IntWritable> {
    Text wordWritable = new Text();
    IntWritable countWritable = new IntWritable(1);

    @Override
    protected void map(LongWritable key, Text value, Context context) {
        String line = value.toString();
        String[] words = line.split(" ");
        for (String word : words) {
            wordWritable.set(word);
            context.write(wordWritable, countWritable);
        }
    }
}
```
- 泛型四参数：`<输入Key类型, 输入Value类型, 输出Key类型, 输出Value类型>`
- `LongWritable`：输入 Key 是每行在文件中的字节偏移量
- `Text`：输入 Value 是一行文本
- 输出 `<单词, 1>` 键值对
- **对象复用优化**：在类成员位置 new Text/IntWritable，在 map 中用 `set()` 赋值，避免频繁 GC

### 3. Reducer 阶段
```java
static class WordCountReducer extends Reducer<Text, IntWritable, Text, IntWritable> {
    IntWritable count = new IntWritable();
    @Override
    protected void reduce(Text key, Iterable<IntWritable> values, Context context) {
        int sum = 0;
        for (IntWritable val : values) sum += val.get();
        count.set(sum);
        context.write(key, count);
    }
}
```
- `Iterable<IntWritable>` 是 Shuffle 后相同 Key 的所有 Value 的迭代器
- 对 values 求和得到单词总频次

### 4. Job 驱动配置
```java
Configuration conf = new Configuration();
Job job = Job.getInstance(conf, "WordCount");
job.setJarByClass(WordCount.class);          // 指定Jar包位置

job.setMapperClass(WordCountMapper.class);   // Mapper类
job.setMapOutputKeyClass(Text.class);        // Map输出Key类型
job.setMapOutputValueClass(IntWritable.class);// Map输出Value类型

job.setReducerClass(WordCountReducer.class);  // Reducer类
job.setOutputKeyClass(Text.class);           // 最终输出Key类型
job.setOutputValueClass(IntWritable.class);  // 最终输出Value类型

FileInputFormat.setInputPaths(job, new Path("/input/a.txt"));  // 输入路径（必须存在）
FileOutputFormat.setOutputPath(job, new Path("/output"));      // 输出路径（必须不存在）

job.waitForCompletion(true);  // 提交作业并等待完成，true打印进度
```

### 5. Hadoop 序列化类型对照表
| Java 类型 | Hadoop Writable | 说明 |
|-----------|----------------|------|
| String | Text | UTF-8字符串 |
| Integer | IntWritable | 整型 |
| Long | LongWritable | 长整型 |
| Double | DoubleWritable | 浮点型 |
| void | NullWritable | 占位，不序列化 |

### 6. Shuffle 过程（面试重点）
```
Map输出 → 分区(Partition) → 排序(Sort) →  Combiner(可选) → 网络拷贝 → Reduce端合并排序
```
- **分区**：默认 HashPartitioner，相同 Key 发到同一个 Reduce
- **排序**：Map 输出按 Key 字典序排序
- **Combiner**：本地预聚合，可减少网络传输（WordCount 中 Combiner = Reducer）

## 三、注意事项
1. 输出目录**必须不存在**，Hadoop 防止覆盖已有数据
2. 输入路径必须是 HDFS 上已存在的文件或目录
3. `setJarByClass` 通过主类定位 Jar 包，必须指定
4. CoreStopWordDictionary.java 与 WordCount 结构一致，作为词频模板参考

## 四、运行方式
```bash
# 上传输入文件
hadoop fs -put a.txt /input/

# 运行
hadoop jar hadoop.jar hadoop01.WordCount

# 查看结果
hadoop fs -cat /output/part-r-00000
```

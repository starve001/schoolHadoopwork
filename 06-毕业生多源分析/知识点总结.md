# 高校毕业生多源数据分析

## 一、实验目标
对多个城市的毕业生数据（商丘sq、洛阳ly、承德cd、许昌xc）做差异化统计：商丘算就业率、洛阳算升学率、承德/许昌算平均薪资。掌握多源文件输入时如何按文件名区分数据来源。

## 二、核心知识点

### 1. 通过 FileSplit 获取输入文件名
```java
String file_name;

@Override
protected void setup(Context context) {
    FileSplit fs = (FileSplit) context.getInputSplit();
    file_name = fs.getPath().getName();
}
```
- 在 Mapper 的 `setup()` 中获取当前 Map Task 处理的文件路径
- `FileSplit` 是 Map Task 的输入分片，每个分片对应一个文件（或文件的一部分）
- `getPath().getName()` 得到文件名（如 `sq.csv`、`ly.csv`）
- **关键**：setup 中获取一次即可，map 中直接用成员变量

### 2. 按文件名分支处理
```java
if (file_name.contains("sq")) {
    // 商丘：第6字段为空 → 未就业
    if (info.length > 5 && info[5].isEmpty()) {
        context.write(new Text("商丘 未就业"), new IntWritable(1));
    } else {
        context.write(new Text("商丘 就业"), new IntWritable(1));
    }
} else if (file_name.contains("ly")) {
    // 洛阳：第7字段含"考研上岸" → 成功
    ...
} else if (file_name.contains("cd")) {
    // 承德：第7字段薪资，支持范围格式 "3000-5000"
    String[] salary = info[6].split("-");
    int avg = (Integer.valueOf(salary[0]) + Integer.valueOf(salary[1])) / 2;
    context.write(new Text("承德"), new IntWritable(avg));
}
```
- 不同城市的数据结构不同，字段位置不同，统计口径不同
- 通过文件名前缀（sq/ly/cd/xc）走不同处理逻辑
- 输出 Key 带城市名，便于 Reduce 端聚合

### 3. 薪资范围解析
```java
// 处理 "3000-5000" 格式
String[] salary = info[6].split("-");
int sal1 = Integer.valueOf(salary[0]);
String salary2 = Pattern.compile("[^0-9]").matcher(salary[1]).replaceAll(""); // 清洗非数字
int sal2 = Integer.valueOf(salary2);
int avg = (sal1 + sal2) / 2;
```
- 薪资可能是固定值或范围，取范围中值
- 用正则 `[^0-9]` 清洗字段中的非数字字符

### 4. Reducer cleanup 阶段计算最终指标
```java
Map<String, Integer> map = new HashMap<>();
int count_cd = 0, count_xc = 0;

@Override
protected void reduce(Text key, Iterable<IntWritable> values, Context context) {
    if (key.toString().equals("承德")) {
        int total = 0;
        for (IntWritable v : values) { total += v.get(); count_cd++; }
        map.put("承德", total);
    }
    // ... 其他城市
}

@Override
protected void cleanup(Context context) {
    double avg_cd = map.get("承德") / count_cd;
    double rate_sq = new BigDecimal((float) map.get("商丘 就业") / total)
            .setScale(2, BigDecimal.ROUND_HALF_UP).doubleValue();
    context.write(new Text("承德平均薪资"), new DoubleWritable(avg_cd));
    context.write(new Text("商丘就业率"), new DoubleWritable(rate_sq));
}
```
- reduce 阶段只做累加，把中间结果存到成员变量 Map
- cleanup 阶段统一计算比率、平均值
- `BigDecimal.setScale(2, ROUND_HALF_UP)` 保留两位小数

### 5. 多文件输入
```java
FileInputFormat.setInputPaths(job, new Path("hdfs://localhost:9000/001/input"));
```
- 输入路径是一个目录，Hadoop 自动读取目录下所有文件
- 每个文件由不同的 Map Task 处理，setup 中能区分文件名

## 三、注意事项
1. 文件名必须能区分来源（sq/ly/cd/xc 前缀），否则无法分支
2. 字段索引要仔细核对，不同 CSV 的列位置不同
3. 空值、表头、异常值要做防护（`info.length > N` 判断）
4. 比率类指标必须在 cleanup 中算，reduce 阶段只有部分数据

## 四、运行方式
```bash
hadoop fs -mkdir /001/input
hadoop fs -put sq.csv ly.csv cd.csv xc.csv /001/input/
hadoop jar hadoop.jar hadoop01.GraduateMain
hadoop fs -cat /out/part-r-00000
```
